# CPS3 Sprite Toolkit

Offline extraction, palette resolution, and upscaling pipeline for Street Fighter III: 3rd Strike (CPS3) sprites.

## Prerequisites

- **Python 3.8+**
- **Pillow** (`pip install Pillow`)
- **NumPy** (optional, ~10× faster compositing: `pip install numpy`)
- **ComfyUI** (only for upscale steps — not needed for extraction)

## Quick Start

Set the AFS path once (or use `--afs` on every command):
```sh
set SF33RD_AFS=C:\path\to\SF33RD.AFS
```

### Extract character sprites
```sh
python extract_sprites.py chars all                # all characters, palette 0
python extract_sprites.py chars ryu --frames 0-10  # specific range
python extract_sprites.py chars --info             # list characters + frame counts
```

### Extract stage/effect sprite groups
```sh
python extract_sprites.py stages all               # all groups
python extract_sprites.py stages --group 52        # single group
python extract_sprites.py stages --list            # list known groups
python extract_sprites.py stages --per-character   # per-char effect variants
```

### Extract stage backgrounds
```sh
python extract_stage.py all                        # all stages, PPG mode
python extract_stage.py 5 --mode=indexed           # stage 5, palette-indexed
python extract_stage.py --help                     # full options
```

### Upscale pipeline (requires ComfyUI)
```sh
# 1. Start ComfyUI
cd D:\ComfyUI_windows_portable && run_nvidia_gpu.bat

# 2. Upscale character sprites (4×)
python comfyui_batch_upscale.py

# 3. Upscale stage layers + retile
python comfyui_batch_upscale_stages.py
```

## Output Structure

```
output/
  sprites/           # Character sprite PNGs (per-character subdirs)
  sprites_4x/        # Upscaled character sprites
  stage_sprites/     # Stage/effect group PNGs (per-group subdirs)
  stages/            # Stage background layers + tile atlases
    stage_00_gill_ppg/
      layer_0.png, layer_0.json    # Full-grid layer + retile metadata
      tiles/tile_000.png ...       # Individual 128×128 tiles
      anim_tiles/anim_000.png ...  # Animation tiles (if any)
      chip_anims_0/frame_0000.png  # Chip-based sprite animations
```

## Module Map

| File | Purpose |
|------|---------|
| `sprite_common.py` | Shared foundation: AFS I/O, LZ decompress, unswizzle, palette decode, data tables |
| `extract_sprites.py` | Unified CLI for stage sprites and character animations |
| `extract_stage.py` | Stage background layer extraction (PPG + indexed modes) |
| `bytecode_parser.py` | Parse engine C source → offline CG-to-palette map |
| `comfyui_api.py` | Shared ComfyUI HTTP client + alpha-preserving upscale workflow |
| `comfyui_batch_upscale.py` | Batch upscale character sprites |
| `comfyui_batch_upscale_stages.py` | Batch upscale stage layers + retile |
| `retile_stage.py` | Split upscaled layer images back into runtime tiles |

## Data Files

`data/` contains binary dumps captured from the engine at runtime:
- `stage_NN_colorram.bin` — 64KB ColorRAM snapshots (512 banks × 64 colors × 2 bytes, ABGR1555 post-swap)
- `stage_NN_ake_ppg.bin` — PPG tile data for brightness/stage-select variations

`cg_palette_map.json` — Generated by `bytecode_parser.py`, maps CG frame numbers to palette banks.

## Environment Variables

| Variable | Default | Used by |
|----------|---------|---------|
| `SF33RD_AFS` | `…\SF33RD.AFS` | `extract_sprites.py`, `extract_stage.py` |
| `SF33RD_SPRITES_ROOT` | `output/sprites` | `comfyui_batch_upscale.py` |
| `SF33RD_SPRITES_4X` | `output/sprites_4x` | `comfyui_batch_upscale.py` |
| `SF33RD_STAGES_ROOT` | `output/stages` | `comfyui_batch_upscale_stages.py` |
| `SF33RD_TILES_OUTPUT` | `assets/sprites` | `comfyui_batch_upscale_stages.py` |
