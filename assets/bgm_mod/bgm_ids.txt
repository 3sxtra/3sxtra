================================================================================
  3SXtra — Modded BGM Reference
================================================================================

To replace a BGM track, place an audio file named {fnum}.ogg (or .flac, .opus,
.mp3, .wav) in this folder (assets/bgm_mod/).

Example: To replace Alex Stage A (arranged), create "572.ogg".

Enable modded BGM in the F3 Mods menu.

LOOP POINTS
-----------
For OGG files, embed LOOPSTART / LOOPLENGTH vorbis comment tags.
SDL3_mixer reads these automatically. Tools like vorbiscomment can set them:

  vorbiscomment -a -t "LOOPSTART=234567" -t "LOOPLENGTH=9876543" track.ogg

For non-OGG files, create a sidecar .loop file (e.g. 572.loop):
  LOOPSTART=234567

Without loop metadata, tracks loop from the beginning.


================================================================================
  AFS ARCHIVE OVERVIEW (file numbers 0 – 1534)
================================================================================

The game's AFS archive contains 1535 files. Audio files are ADX format.
Below is a summary of the archive layout:

  0000 – 0090    Graphics, palettes, fonts, data, memory card icons, ADX packs
  0091 – 0571    Arcade (Original) soundtrack BGM
  0572 – 1362    Arranged (Dreamcast) soundtrack BGM
  1363 – 1534    Character sprites, stage backgrounds, effects, SPU banks


================================================================================
  STAGE & CHARACTER REFERENCE
================================================================================

This is NOT the same as the original arcade game's internal stage numbering.

  - Arranged: 3 variants per stage (A / B / C), cycling { A, B, C, B, C, B, C, B }
  - Arcade:   2 variants per stage (A / B), alternating { A, B, A, B, A, B, A, B }

================================================================================
  HOW TO MOD A STAGE BGM (QUICK START)
================================================================================

1. Find your target stage in the STAGE → BGM CODE MAPPING above
2. Note the BGM code(s) used
3. Look up the fnum(s) in the appropriate BGM table (arranged or arcade)
4. Create {fnum}.ogg (or .flac/.opus/.mp3/.wav) in this folder
5. Enable "Enable Modded BGM" in the F3 Mods menu

For seamless tracks, the engine loads the fnum from the BGM table as the
"intro" track, then chains through subsequent AFS files from the segment
range. To replace the full track, you may need to replace all files in
the segment range, or provide a single file for the intro fnum with loop
points set — the engine will play your modded file instead of chaining.

  EXAMPLE: Replace Ryu's Arranged Stage BGM (all 3 variants)

  Ryu = Stage 2 (Dojo) → BGM codes 13, 14, 15
    Code 13 → fnum 776  →  create 776.ogg   (variant A)
    Code 14 → fnum 790  →  create 790.ogg   (variant B)
    Code 15 → fnum 808  →  create 808.ogg   (variant C)

  For seamless mode, also create files for the first segment fnum:
    Code 13 → first seg 777  →  create 777.ogg
    Code 14 → first seg 791  →  create 791.ogg
    Code 15 → first seg 809  →  create 809.ogg

  EXAMPLE: Replace the Character Select music (arranged)

  Character Select = BGM code 53 → fnum 1348
    create 1348.ogg
    (or use voice_mod/emsel.ogg for voice-channel replacement)
